Architecture Notes:
• Multi-Tenancy: Every organization-owned entity has organizationId. All queries scoped by TenantGuard.
• RBAC: 6 roles — OWNER, ADMIN, RECRUITER, HIRING_MANAGER, INTERVIEWER, VIEWER.
• Distribution: JobBoardConnector interface abstracts publishing. LinkedIn uses manual workflow (MVP).
• Auth: JWT (access 15m + refresh 7d). Refresh rotation on every refresh call.
• Database: 18 core tables. Prisma ORM. Backend-enforced tenant isolation.
